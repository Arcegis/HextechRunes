# 受减益触发与夜狩

扇巴掌、折磨者、巨像的勇气通过 `AfterPowerAmountChanged` 监听仍存活的敌人实际收到减益，不再监听敌人对玩家施加减益或自身增益。增加同一种减益也算一次；同一张牌作用于多个敌人时，各敌人独立记录。普通减益减少层数、临时属性的包装 Power 不触发；外部施加的负力量等双向属性在实际属性变化时计一次，临时力量到期的自扣不触发。

三者沿用原有每名敌人的回合计数器，在玩家侧回合开始重置，上限分别为 3、3、2。扇巴掌使用独立的 `HextechSlapTemporaryStrengthPower`，按原版 TemporaryStrength 生命周期收回；折磨者向每名存活玩家施加 1 层灼烧；巨像的勇气取最大生命值的 1/2/3%，向下取整且最低 1 层，沿用原覆甲应用路径。

夜狩与狂徒豪气共用抽牌进度计算，每位玩家分别累计，跨回合保留。阈值固定 12，不按联机人数调整；每满一次向存活敌人添加 1 层滑溜，使用 `ApplyExact` 绕过原版滑溜联机倍增。独立的 `NightstalkingPlayerCardsDrawnThisCombat` 同时接入 Tracking 与 Snapshot，避免与狂徒豪气相互消费进度，战斗结束清空。联机沿用狂徒豪气既有的出牌后、回合开始后和结束前历史补记时点；本次不改其触发时序。

我方罪恶快感保留既有默认禁用；敌方使用可修改的默认禁用集合，不从可配置内容目录硬删除。配置 v36 为旧配置补上敌方禁用项一次，之后手动重新启用仍有效，不清除其他自定义配置。

本次新增一个 Power 模型和一个战斗追踪 JSON 字段，没有新增 SavedProperty 属性。联机各方应使用同一构建；实际多人抽牌、滑溜消耗和临时力量到期效果留给用户测试。
