# 五个敌方升级海克斯

版本保持 0.9.3，目标保持 0.107.1 / 0.110.0 / 0.111.0。新增敌方枚举仅追加 135–139，不重排旧 ID；不新增 SavedProperty。使用既有战斗计数字典保存技能次数与每名敌人的偷牌次数。联机双方仍须使用同一份更新包。

## 结算约定

- 活雾：每名玩家每回合最多开始打出三张技能，手动与自动打出共同计数。同一张牌的重放不重复占用名额；在 BeforeCardPlayed 中计数，防止技能内部自动打出越过上限。下一玩家回合恢复名额。与原版 SmoggyPower 不同，这是明确的三张上限，不施加原版只能打一张技能的迷雾附魔。
- 仪式兽：保留原来的所有意图和行动，包含攻击时追加一次获得 1/2/3 力量的意图；整次行动后获得力量。多段伤害不多次加力量。珠光护手实际重复一次行动时也结算一次追加效果。
- 灵魂异鱼：AfterShuffle 只给执行洗牌的玩家加入 1/2/3 张原版 Beckon（呼唤），随机插入抽牌堆；不按敌人数乘算，也不额外附加原版灵魂异鱼本体的强制出牌规则。
- 幽灵船：首次玩家回合、牌堆建立后，给每名玩家的弃牌堆加入 2/3/4 张原版 Dazed（晕眩）。额外回合和召唤不会再次触发。
- 偷窃草蜢：遵循用户最后确认的原版时序，敌人本轮追加偷牌意图，执行原行动后、仍在同一次行动结算中偷牌。敌人行动时手牌通常已弃掉，因此沿用原版抽牌堆/弃牌堆与 DeckVersion 筛选、稀有度优先级。每个敌人每场战斗只偷一张，联机时先选一名有可偷卡牌的存活玩家，再选牌；没有可偷牌时不消耗次数、不逃跑。成功后下一次行动改为逃跑，玩家有完整一轮追杀机会。
- 首领保护使用原版首领遭遇 + 主敌人身份。眩晕、Asleep/Slumber 睡眠、Minion 仆从及已有逃跑意图的敌人不会计划或执行偷牌。Minion 的退场常与首领死亡回调绑定（如女王的 TorchHeadAmalgam），不能用逃跑绕过遭遇关系；睡醒且不再眩晕的普通敌人仍可偷牌。
- 逃跑状态通过 FollowUpState 自循环保留到下一轮，不锁住 CanTransitionAway；允许千足虫 ReattachPower 的 SetMoveImmediate(DeadState) 和原版眩晕等流程覆盖意图。
- 偷牌使用原版 SwipePower.Steal 和 SwipePower.BeforeDeath：移除牌组原件，击杀后按原版额外卡牌奖励归还；逃跑使用 CreatureCmd.Escape，不触发死亡返还。视觉使用待机模型向右平移。
- 默认禁用自动巡逻，保留模型、既有存档效果与配置手动开启入口。

## 补丁裁决

| 目标 | 缺少的原版扩展点 | 处理 |
| --- | --- | --- |
| MonsterModel.RollMove | 没有修改下一行动意图的模型 Hook | Postfix 追加自己的意图；稳定随机以战斗、敌人 ID 和回合为键 |
| MonsterModel.SetMoveImmediate | 强制变更意图同样没有 Hook，且方法内部会刷新界面 | 非跳过 Prefix 仅向传入行动追加力量意图，保留原状态机对象 |
| MoveState.PerformMove | 原版行动前后没有通用模型 Hook，AfterAttack 不能表达整次行动且会重复计算多段命令 | Postfix 等待原任务完成，仅执行带本模组意图标记的追加效果 |

意图列表访问复用 HextechHookReflection 集中解析的 MoveState.Intents 支持字段，不访问第三方类型或 Hook 分发中枢，不替换原攻击委托。逃跑使用公开的 MoveState、状态表和 SetMoveImmediate，并设置 MustPerformOnceBeforeTransitioning，避免后续 RollMove 跳过尚未执行的逃跑。

静态回归覆盖新增身份与稀有度、意图保留与防重复、原版状态机下一轮保留逃跑、每名玩家技能计数、每名敌人偷牌次数的保存/恢复、首领保护和默认禁用配置。0.107.1 / 0.110.0 / 0.111.0 均通过 295/295 项，构建零警告、零错误。三个新增补丁目标全部通过解析和清单检查；SavedProperty 与可变静态字段集合没有新增变化。

完成九种语言资源检查、五张 256×256 贴图的 Godot 无界面读取、PCK 全部 1,460 个文件的 MD5 校验，以及包含稳定加载器和三个实现变体的 10 文件 ZIP 检查。Godot 首次受限导入进程退出 139，在正常本机环境重试完成。未将打包进程视为模组实际加载或游戏玩法验证。

交付包：`releases/HextechRunes-0.9.3-five-enemy-upgrades.zip`。已部署到本机游戏 `Contents/MacOS/mods/HextechRunes`，10 个文件逐一通过 SHA-256 比对。旧构建备份位于 `.build/before-enemy-upgrades`。默认配置版本由 34 迁移为 35，只追加自动巡逻的默认禁用项；迁移后重新开启的用户选择不会被重复关闭。
