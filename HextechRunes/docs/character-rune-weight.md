# 角色专属海克斯动态权重

## 玩家规则

- 三个位置均从当前合法池混合抽取，不再预留角色专属位置，也不设置额外的固定轮数保底；
- 每名玩家新一局的专属权重倍率为 150%，通用候选为 100%；
- 每次抽出一个非专属候选，专属倍率增加 10 个百分点；抽出一个本角色专属候选，减少 10 个百分点。三个位置依次抽取，后续位置立即使用更新后的倍率；
- 重掷成功生成的候选也计一次，未发生替换不计。计数依据是刷出候选，不是最终拿取；
- 倍率最低为 0%，不设置额外的玩法上限。若合法池只剩专属且倍率为零，按原有标签权重抽取以避免空选项；
- 与现有标签权重相乘，并继续排除已拥有、互斥、禁用等不合法候选；同组三选一最多出现一个卡牌升级类海克斯；
- 权重按玩家独立累计，跨稀有度、幕和无尽循环保留，新一局重置。没有映射到原版角色池的模组角色不推进专属权重；
- 混沌实验室仍在普通候选生成后执行替换。本体权重根据被抽出的普通候选计数，混沌替换不产生第二次计数。

例：初始 150%，依次刷出通用、通用、专属，三个位置实际使用 150%、160%、170%，结束后为 160%。

## 保存与联机

`HextechWeightedRuneOptions` 携带一次选择的权重快照。生成、UI 复制和重掷不会修改本局权重；取消选择不会提交。本地与远端确认结果后，统一提交绝对值，不按最后三个候选重新推算被重掷覆盖的历史。

最终候选 ID 后附带 `-11` 和结束倍率，再接已有的混沌配方数据。远端缺失倍率或格式错误时中止该选择，禁止默默回退到 150%。

沿用 `SavedRuneSelectionJournalJson`，在 JSON 中追加按玩家 ID 排序的 `characterWeights`，没有新增或改名 SavedProperty。旧存档缺少这部分数据时从 150% 开始；多人检查点恢复跳过已确认选择，不重复推进。无尽循环清理选择流水时保留倍率。

## 验证

自动回归覆盖相对概率区间、顺序增减、标签乘区的小数精度、零权重与仅专属池、无角色映射、每玩家独立保存、旧数据恢复、重复提交、不同玩家完成顺序、候选复制、重掷快照、联机尾部截断及负值、倍率与混沌配方同时传输。

0.107.1、0.110.0、0.111.0 三个维护目标均通过 277/277 项回归检查，编译零警告、零错误；包含模型身份、SavedProperty 和补丁清单检查。尚未进行游戏内选择、实际存档重载或双客户端联机验证。

实机由用户验证：连续三选一与重掷、存档重载、跨幕/无尽累计、两名不同角色同时选择、混沌实验室共用时的候选与联机状态。
