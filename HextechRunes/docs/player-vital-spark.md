# 玩家侧活力火花

`HextechVitalSparkPower` 是可叠层的玩家负面效果，复用原版活力火花图标、`Tainted` 卡牌侵蚀及 `TaintedPower` 污染结算。通过 `PowerCmd.Apply<HextechVitalSparkPower>(...)` 施加。敌方棱彩“升级：感染棱柱”在战斗开始时给予所有玩家 0/1/2 层，替代原敌方“秘术冲拳”。

- 仅持有者的所有战斗牌堆中的技能牌获得对应层数污染；中途施加和后续生成技能同样生效，不牵连队友。
- 首次施加、增加和减少层数均同步已有污染技能的层数；不覆盖其他类型侵蚀。使用原版单侵蚀槽规则。
- 持有者打出污染牌后，由此 Power 施加当前层数的原版污染。污染的受击增伤及敌方回合结束清除由原版处理。
- 负面类型让人工制品与净化遵循原版流程；移除时扣除本效果的污染牌层数，若仍有原版活力火花则保留其层数，否则清除侵蚀。不清除玩家此前已经获得的污染状态。祸水东引按已有规则只移除此玩家专属效果，不转移给敌人。
- 牌上的污染层数为本玩家的模组层数加场上原版活力火花总层数；打出时每个 Power 只施加自己的污染，避免重复乘算。例如原版 2 层加模组 1 层，技能显示 3，打出后合计获得 3 层污染。

## 原版兼容挂钩

原版 `BeforeCombatStart` 会叠加卡牌侵蚀、`AfterPowerAmountChanged` 会覆盖其数值、`AfterRemoved` 会清除全队污染。正常模型 Hook 无法保证在原版写入后执行，因此在这三个具体方法上追加等待原 Task 的 postfix，随后只重算仍持有 `HextechVitalSparkPower` 的玩家。没有持有者时不改牌，也不跳过或替换原版结算。

敌方身份继续使用 `MonsterHexKind.ArcanePunch = 81`，保存/配置键保持不变；旧攻击牌计数保留序列化兼容但不再参与效果。展示载体改为只供敌方使用的 `InfestedPrismHex`，使用用户提供的 `infestedPrismHex.png`，我方“秘术冲拳”保持原样。

模型没有新增 SavedProperty、随机数或战斗静态状态。0.107.1 使用既有手动类型注入；后续版本由官方模型发现注册。Power 图标复用已有解析入口，三个原版兼容挂钩均登记于补丁清单。
