# 敌方海克斯生命周期修复

## 偷窃草蜢

- AsleepPower、SlumberPower 不属于原版 IsStunned，计划偷牌和行动结束实际偷牌时都排除这两种睡眠。
- MinionPower 单位不能偷牌逃跑。女王只通过 AfterDeath 更新仆从死亡标记，CreatureCmd.Escape 不发送死亡回调；让其仆从正常留在遭遇中，避免修改女王或伪造死亡事件。
- 逃跑状态使用原有 FollowUpState 自循环即可在 RollMove 后保留，不再设置 MustPerformOnceBeforeTransitioning。该锁会让 ReattachPower 的普通 SetMoveImmediate(DeadState) 失效，挡住千足虫复活。仍按原版 SwipePower 的死亡回调归还偷走的卡牌，每个敌人的偷牌次数不因复活重置。

## 鲜血神像

战斗仍在正常进行时保留原有 Damage 命令和致死规则。战斗已经结束、正在结束或没有战斗状态时，使用 CreatureCmd.SetCurrentHp 扣除 1 点生命，最低保留 1 点，并继续发送原版生命变化回调。奖励界面的死亡不再交给已经停止的战斗流程处理；也避免非战斗伤害修正把扣血放大到致死。

## 验证边界

仅开启敌方海克斯时，选择协调器在我方数量为 0 且本幕确有新增敌方海克斯时显示独立确认界面，沿用现有重掷次数、移除/撤销及敌方选择同步消息。联机房主调整并确认，客机同步预览，在收到最终消息后完成；不生成玩家候选、不发放玩家遗物。固定挑战仍按其原定敌方配置执行。界面未确认退出不标记该幕完成。

针对睡眠/仆从筛选、逃跑意图经过 RollMove 后保留、原版 SetMoveImmediate 能覆盖待执行逃跑、1 点生命领奖、仅敌方模式的确认分支与现有敌方同步协议进行回归。实机需检查大蜘蛛睡醒、千足虫倒地复活及卡牌归还、女王正常指挥仆从、单人及联机战后领奖，以及仅敌方模式重掷、确认和手柄导航，自动回归不代替这些实测。
