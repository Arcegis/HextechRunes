# 一呼百应等五个海克斯

## 结算约定

- 一呼百应（通用黄金）：在 `AfterCardPlayed` 读取持有者抽牌堆、手牌的快照，按模型 ID 匹配同名牌，升级与附魔不影响匹配。先处理抽牌堆，再处理手牌，保留各牌堆顺序。排除触发牌自身；同一批自动打出不会递归启动另一批，故放血回手等效果不会形成自身无限重入。逐张执行前复查牌堆及战斗状态；优先沿用原目标，目标死亡则按 CombatId 选择存活可命中的敌人。使用原版自动打牌命令，不支付资源，不绕过无法打出和其他模型的禁止出牌规则。
- 轮转不息（通用棱彩）：每次持有者的 `AfterShuffle` 都处理当时手牌，没有每回合次数限制。能量使用整回合减费，辉星使用临时费用及 `TryModifyStarCost` 延续优惠（原版辉星 ThisTurn 也会在打出后清理）；打出再回手仍然免费。原版费用清理与持有者 `AfterSideTurnEndLate` 共同恢复原费用。此次洗牌后才抽到的牌不属于快照。X 费沿用原版 X 费规则。
- 见血封喉（猎人棱彩）：小刀每段攻击的加算伤害等于实际目标的中毒层数，再接受原版攻击伤害修饰与格挡。预览使用相同公式。复用小刀身份规则，因此“大号匕首”替换的君王之剑也能受益；不是额外的一次伤害事件。
- 森罗万象（故障机器人棱彩）：`BeforeSideTurnEndEarly` 确认持有者在本次结束回合的参与者中，再冻结充能球队列并按模型 ID 统计种类。两闪电一冰霜为 2 种，对所有球额外执行 2 轮被动。0.110/0.111 使用原版 `TriggerPassive`；0.107.1 调用原版次数修饰 Hook 后逐次使用 `OrbCmd.Passive`。等离子及模组球也参与。已离开队列的球不继续触发，新生成的球不扩大本批次，战斗结束立即停止。
- 王国军势（储君棱彩）：每次正数 `AfterForge` 事件生成 1 张仆从，与铸造数值和君王之剑数量无关。使用现有三种仆从池与稳定随机，消费现有同步计数容器中的事件序号，复用原版生成卡入手流程及满手处理。

## 身份与兼容

五项在注册表末尾追加，原有登记顺序、角色序号不变；没有新增 SavedProperty 或 Harmony 补丁。版本沿用 0.9.3，联机各端必须更新同一份文件。

## 验证范围

自动检查覆盖候选快照、费用持续与回合恢复、种类去重、目标中毒伤害、注册稀有度与角色池以及原版命令调用路径。发行包分别构建当前维护的 0.107.1、0.110.0、0.111.0 变体。

三个目标各通过 285/285 项检查，发行编译均为零警告、零错误。资源包 1427 个文件哈希一致，五张导入贴图均可从 PCK 加载为 256×256 纹理；九种语言的新增键、标签和变量一致。ZIP 与本机部署的 10 个文件均与 dist 一致。

实际游戏和联机交由玩家验证，重点：一呼百应配合放血回手及抽牌/消耗；同回合多次洗牌与辉星牌；小刀多目标和大号匕首；混合球、额外回合与被动致死；多次铸造、满手和两人同步生成仆从。
