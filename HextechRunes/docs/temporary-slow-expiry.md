# 百炼成钢临时缓慢的回合清理

## 根因与修复

水银沙漏在 `AfterPlayerTurnStart` 造成不受普通伤害倍率影响的伤害。敌方百炼成钢收到该伤害后叠加负临时缓慢，而旧实现到 `AfterSideTurnStart` 才清理临时缓慢。叠层回调会刷新整个实例的 `_appliedRound`，导致此前累积的层数也被当成本回合新增，连续多个回合逃过清理。负缓慢达到 -100 后普通伤害倍率为零，沙漏本身仍能造成伤害并继续触发。

修复限定在 `HextechTemporarySlowPower` 自身：

- 使用官方 `BeforeSideTurnStart` 清理上一回合的临时层，早于水银沙漏和玩家冰霜幽灵的回调。
- 若其他回调先于清理叠层，按“变化后的总量减本次新增量”识别旧层并扣除，只给新增层记录当前回合；不延长旧层期限。
- 旧层与新层符号相反且暂时抵消到零时，先修正隐藏计数，再调整显示缓慢，避免原版在回调结束后把仍有本回合层数的实例移除。
- 内部扣除旧层不会再次被当成新施加的临时缓慢；永久缓慢保留。同回合的正常叠层及额外回合规则不变。

原版 `PowerCmd.ModifyAmount` 先更新层数，再派发 `AfterPowerAmountChanged`，最后检查是否移除零层实例，以上修正依赖这个公开命令契约。不增加 Harmony 补丁或 SavedProperty，不针对水银沙漏或冰淇淋写特例。
