# 濒死狂宴红光

使用本机原版 0.111.0（commit `41cef1ea`）SOUL_NEXUS 图集的 `glowie` 区域，未改色、未重绘。源路径为 `res://animations/monsters/soul_nexus/soulnexus.png`，图集尺寸 1063 × 656，裁切区域 `(2, 77, 580, 577)`，无旋转。原始 Spine 插槽 `glowie` 为普通混合，`glowie2` 为加色，两者颜色均为白色。

`assets/images/effects/near_death_feast/soul_nexus_glow.png` 保留裁切后的颜色与半透明通道。模组自己打包该纹理，运行时不依赖原版图集位置、Spine 或怪物场景脚本。素材权利归原游戏权利方。

`HextechNearDeathFeastVisual` 为我方与敌方共用显示路径，沿用只读的濒死强度判断和角色背后渲染层。两张 Sprite 复用同一张缓存纹理，取代原先的渐变光圈、扩散圆环和闪光节点；保留濒死强度相关的心跳、进入/加深濒死时的亮度脉冲，并缓慢旋转加色层。这里复用的是原版红光素材与混合方式，并非播放怪物整套骨骼动画。死亡或脱离濒死时隐藏，角色节点销毁时释放显示节点，不增加战斗状态或共享 RNG 调用。

重新提取可用 `tools/extract_near_death_feast_glow.gd`，参数为原版 PCK 和输出 PNG 的绝对路径，使用 Godot 4.5.1。游戏更新导致图集变化时，先核对 `.atlas` 中 `glowie` 的坐标；脚本只检查整张图集尺寸，不能识别同尺寸重排。

红光中心位于碰撞框从底向上的 64% 处，基础宽度为夹取至 120–360 像素后的碰撞框宽度的 2.45 倍，两层同步缩放。

实机观察：玩家与敌人进入濒死后红光应在身体后方显示；继续受伤时增强；退出战斗及角色消失后不应残留。实际战斗尺寸、亮度和多人显示由用户验证。
